# Contributing

1. Read `AGENTS.md`, `docs/project/STATUS.md`, `docs/project/TASKS.md`, `docs/project/HANDOFF.md`, and `docs/04-ARCHITECTURE.md`.
2. Work on exactly one task ID unless a task packet explicitly groups tasks.
3. Run the mandatory Graphify preflight and at least one task-specific graph query before broad code search.
4. Write or update tests before declaring behavior complete.
5. Run `python scripts/verify.py --full` when the required toolchains are installed.
6. Update project state and Graphify evidence after every AI instruction/task.
7. Do not commit or push unless the human asks. Always provide a suggested Conventional Commit message.

Pull requests must be narrow, reviewable and linked to a task ID.
